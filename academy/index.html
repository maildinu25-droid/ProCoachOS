Data export

Downloads every record in this organization — teams, players, sessions, matches, assessments, and everything else — as one JSON file.

Data import / restore

Restores from a previously exported JSON file into your current organization, matching records by their original ID (safe to re-run — existing records are updated, not duplicated).

Deliberately excludes memberships and coach qualifications — restoring access from a file would silently reinstate permissions rather than going through a real invite. Re-invite coaches instead. Also: this works cleanly restoring into the same Supabase project it was exported from. Restoring into a different project may fail on rows tied to a specific coach account (created_by, assessed_by, coach_id) since that user won't exist there.
